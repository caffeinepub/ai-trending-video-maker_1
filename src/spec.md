# Specification

## Summary
**Goal:** Fix navigation from trending topics to the AI script generator so users can create videos from trending topics.

**Planned changes:**
- Update TrendingTopicCard component to properly pass topic data when navigating to VideoConfigurationPage
- Ensure VideoConfigurationPage correctly receives and displays topic data from navigation
- Verify the 'Generate Script' button triggers script generation without errors

**User-visible outcome:** Users can click "Create Video" on any trending topic, see the topic title on the configuration page, and successfully generate AI scripts for that topic.
